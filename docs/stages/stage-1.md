# Stage 1：分歧验证

## 状态
[ ] 规划中 / [ ] 进行中 / [ ] 完成

## 目标

用最少的代码回答一个问题：**同一个 IP，不同数据源给出的结论是否经常互相矛盾？这个矛盾对目标用户有没有意义？**

这是整个项目的存亡假设。如果分歧罕见，或者用户根本不在乎，那么后面所有的工程设计都是浪费。

## 非目标

- 不追求代码质量、不写测试、不做错误处理
- 不做 Web 界面
- 不接入所有源，4–6 个足够
- 不对比"别的检测站"的评分本身（那需要爬站，且不道德）；对比的是**各原始源的结论**

## 核心假设

- **H1**：同一 IP 在多个独立源的结论中，至少有一项（归属地、类型、信誉）存在矛盾，并且这个矛盾发生率 > 30%
- **H1b**：目标用户（跨境卖家 / 代理使用者 / Linux 运维）看到并列结论后，认为比单个分数更有用

## 方法

### 1. 样本集

准备 50–100 个 IP，覆盖假设中会出现分歧的类别：

| 类别 | 数量 | 来源 |
|---|---|---|
| 自己的 VPS | 3–5 | 手头现有 |
| 云厂商（AWS / 腾讯云 / OVH） | 10 | 已知 |
| 公共 DNS（8.8.8.8、1.1.1.1、223.5.5.5 等） | 10 | 已知 |
| 住宅 ISP（家宽、手机网络） | 10 | 自己的、朋友提供的 |
| 代理 / 机房段 | 10 | 已知 |
| 随机 IPv4 | 20 | rand |
| IPv6 | 10 | 各种来源 |

### 2. 拉取的源

| 维度 | 源 | 免费额度 |
|---|---|---|
| ASN / 前缀 | Team Cymru DNS (`dig TXT <reversed>.origin.asn.cymru.com`) | 无限制 |
| 注册信息 | RDAP via `rdap.org` | 无限制 |
| 反向解析 | PTR 查询 | 无限制 |
| 地理 / 类型 | MaxMind GeoLite2（本地 mmdb） | 无限制（需注册下载） |
| 信誉 | Spamhaus ZEN DNSBL | 有查询限制但够用 |
| 滥用报告 | AbuseIPDB API | 1000/天 |

### 3. 输出

每个 IP 一张对照表：

```
=== 8.8.8.8 ===
ASN         AS15169  GOOGLE
前缀        8.8.8.0/24
注册国      US (ARIN, 1992-12)
rDNS        dns.google
MaxMind     美国 / Google LLC / 类型: hosting
Spamhaus    未列入
AbuseIPDB   0 报告 / 0% 置信度
--- 一致性判定 ---
注册国 vs 地理国: 一致
rDNS 与 ASN 归属: 一致
```

### 4. 判定逻辑

只做最简单的比较，不做加权：

| 判定项 | 规则 |
|---|---|
| 地理一致 | RDAP 注册国 == MaxMind 国家 |
| 归属一致 | rDNS 中出现的组织 == ASN 注册组织（模糊匹配） |
| 类型可疑 | MaxMind 标记 hosting/proxy/vpn/tor |
| 信誉可疑 | 任一黑名单命中 或 AbuseIPDB 置信度 > 25 |

### 5. 统计

- 存在 ≥1 项不一致的 IP 占比
- 各类别的不一致率（云厂商 vs 住宅 ISP 应该差别明显）
- 最常出现分歧的字段

## 验收标准

- [ ] 50 个以上 IP 完成拉取，结果落盘为可复查的文本/JSON
- [ ] 统计出不一致率
- [ ] 找到至少 3 个具体案例：同一个 IP，A 源说 X，B 源说 Y
- [ ] 把 3 个案例拿给至少 2 个目标用户看，记录他们的反应原话
- [ ] 写出结论：H1 成立 / 不成立 / 部分成立

## 回滚方案

无代码需要回滚。脚本和结果放 `cmd/probe/` 与 `docs/stages/stage-1-findings.md`，如果 H1 不成立，整个仓库存档即可。

## 已知局限

- 只对比原始源，不对比各家检测站（爬站不道德且结果不可引用）
- 样本量小，结论只是方向性的
- MaxMind 免费版精度低于商业版，可能引入伪分歧

## 对后续 Stage 的影响

- H1 不成立 → **项目终止**，这是本 Stage 存在的唯一目的
- H1 成立 → 分歧的形态决定 Stage 4 的展示设计（哪些字段要并排、哪些要折叠）
- H1b 不成立（用户不在乎）→ 重新考虑定位：可能只做给运维的工具，不做给跨境人群
