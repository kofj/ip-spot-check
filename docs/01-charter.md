# 项目章程

**最后更新**：2026-10-31

## 愿景

一个把多家 IP 数据源结论**并列呈现**、不合并成总分的检测工具。用户能自己看到证据链，而不是接受一个无法验证的数字。

## 目标

1. 粘贴一个 IP，一屏内看到路由 / 注册 / 地理 / 信誉各层的原始终端结论
2. 每个数据字段标注来源，任何结论可被复现
3. 记录变更时间序列——同一个 IP 上次查和这次查有什么不同
4. 长期维持"不接受 IP 商家付费"的公开政策

## 非目标

1. **不做总分。** 不打 87 分，不做"纯净度排行"
2. **不做全量 IP 静态页。** 索引大小由真实需求决定
3. **不做独立的"Linux 攻击 IP 情报"产品线。** 降级为观测维度
4. **不接 IP 商家、代理商、测评机构的任何付费**——广告、赞助、联盟推广、软文一概不接
5. **不做 SLA。** 这是一个 fun 项目，随时可以关站

## 成功标准

- [ ] MVP 上线：单 IP 查询返回 6 个源的并列报告
- [ ] `curl <domain>/1.1.1.1` 返回纯文本，论坛/运维可直接用
- [ ] 同一 IP 二次查询能看到字段变更
- [ ] 发布到 V2EX / 主机论坛后，有人主动发自己的 IP 来对照
- [ ] 月成本 < $20，无收入也能维持

## 边界

**范围内：**
- 单 IP 查询（IPv4 / IPv6）
- 多源并列展示与历史对比
- 纯文本接口
- ASN 页（真实搜索需求）

**范围外：**
- 批量 / CIDR / 域名查询（Pro 功能才有）
- 账号体系、告警、仪表盘（Pro 功能才有）
- 评分与排名
- 蜜罐与威胁情报产品化
